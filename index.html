On a standalone headset that memory is shared by the OS, the CPU and the GPU. Run out of frame time and you drop frames. Run out of memory and the game gets closed.

  1. 01

    Memory optimization

    I look at what's actually sitting in memory: textures, fonts, meshes, assets that got loaded twice or are never used. Then I cut it down and add build checks so it doesn't grow back. On standalone VR and consoles, running out of memory means a crash, not just a slowdown.

    You get a smaller memory footprint, measured on the device, and checks in your build.

  2. 02

    Profiling and audits

    I profile your game on the hardware it ships on and find out where the CPU time, GPU time and memory go. Then I write a short report: what's expensive, why, and what I would fix first.

    You get a report with captures and a prioritized list of fixes.

  3. 03

    CPU and GPU optimization

    Draw calls and batching, moving CPU work into compute shaders, expensive shaders and overdraw. I can do the fixes myself or together with your team.

    You get before and after numbers from the target device.

  4. 04

    Rendering features

    Shaders, compute passes and other rendering features in Unity, or in a custom C++ engine with Vulkan or DirectX 11. I plan them around your frame and memory budget from the start.

    You get a feature that fits the budget, with notes for your team.

Case study

Forefront: memory and GPU optimization for a 32-player VR shooter

Studio
Triangle Factory
Role
Graphics & optimization programmer
Engine
Unity
Recognition
Nominee, Best VR/AR Game, The Game Awards 2026
  • Removed duplicate fonts and textures from memory: 148 MB less RAM, measured in the Unity Memory Profiler. Unity makes it surprisingly easy to load the same asset twice.
  • Added a build-time check that stops duplicate fonts from creeping back in.
  • Custom build actions and memory stripping, so less data ends up in the build and in RAM.
  • Moved far-scenery batching from the CPU to the GPU with compute shaders and indirect draw calls.
  • Shipped player-facing features too: weapon sight colour customization, the credits screen and vehicle skins.
